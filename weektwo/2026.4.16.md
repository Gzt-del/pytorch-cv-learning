## 一、今日学习知识点
1. 神经网络基类 nn.Module
模型定义：理解了所有神经网络必须继承 nn.Module。掌握了双核心结构：
__init__：声明层结构（如 nn.Linear），初始化模型权重。
forward：定义前向传播逻辑，描述数据流向。
层组件：重点掌握了 nn.Linear(in_features, out_features)，理解其内部自动维护的 weight 和 bias 张量。
2. 损失函数与优化器
准则函数 (Criterion)：学习了 nn.MSELoss()（均值平方误差），用于衡量模型预测值与真实标签的差异。
优化算法 (Optimizer)：掌握了 torch.optim.SGD（随机梯度下降），理解其通过 optimizer.step() 自动更新 nn.Module 中标记为 requires_grad=True 的参数。
3. 模型训练全管线 (Training Pipeline)
系统梳理了模型训练的五个标准步骤：
数据准备：构造特征张量 X 与标签 y。
前向传播：模型接收输入，产生预测值 y_pred。
计算损失：调用损失函数评估预测效果。
反向传播：执行 loss.backward() 计算参数梯度。
更新参数：利用优化器更新权重，并执行 optimizer.zero_grad() 清空梯度。
## 二、遇到的问题
模型参数未更新：在循环训练中，损失值 (Loss) 保持不变，模型没有学习迹象。
输入维度不匹配：调用 model(X) 时报错，提示矩阵乘法维度不兼容（如 1x1 与 100x1 冲突）。
梯度清零遗忘：未在每次迭代开始前执行 zero_grad()，导致梯度累加，损失函数值出现异常跳变或直接变为 NaN。
数据类型冲突：PyTorch 默认线性层为 Float32，但输入数据有时被推断为 Double (Float64)，导致 RuntimeError。
## 三、解决方法
维度对齐检查：使用 X.view(-1, 1) 或 X.unsqueeze(1) 确保输入张量的形状符合 [batch_size, input_features] 的要求，通过打印 X.shape 实时追踪。
强制类型转换：在构造张量时显式指定 dtype=torch.float32，或在输入模型前执行 X.float()，确保数据与权重类型一致。
标准化训练模板：总结并固化“清零 -> 前向 -> 计算损失 -> 反向 -> 更新”的代码模板，将其作为肌肉记忆，避免逻辑遗漏。
Python
optimizer.zero_grad()   # 1. 清零
outputs = model(inputs) # 2. 前向
loss = criterion(outputs, labels) # 3. 损失
loss.backward()         # 4. 反向
optimizer.step()        # 5. 更新
参数状态监控：通过 list(model.parameters()) 查看权重值的变化，验证反向传播是否生效。
